---
name: One question, one place
description: Why per-holder document and mailing actions belong alongside the year’s financial grid.
---

The user's standing rule for this app is “one question, one place.”

**Why:** The user could not find Resend in the Holders table when it lived on a
separate signing status list, despite the feature existing.

**How to apply:** When extending a workflow, check whether it would make a person
look in two places to answer the same question. Prefer one place over adding
another navigation destination.
